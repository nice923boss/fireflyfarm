# 飛螢農莊 網站後台操作說明

網站正式網址：<https://nice923boss.github.io/fireflyfarm/>
後台網址：<https://nice923boss.github.io/fireflyfarm/admin/>

後台沒有帳號密碼。登入的唯一憑證是您自己在 GitHub 建立的「Fine-grained Personal Access Token」（以下簡稱 Token）。
Token 等同於「可以修改網站內容的鑰匙」，請只保存在自己手上，不要貼給任何人，也不要存在網站或任何檔案裡。

---

## 一、第一次使用前：開啟 GitHub 兩步驟驗證（2FA）

Token 綁在您的 GitHub 帳號上。帳號若被盜，網站就會被改。請先開啟兩步驟驗證。

1. 登入 GitHub，點右上角頭像，選「Settings」。
2. 左側選單點「Password and authentication」。
3. 在「Two-factor authentication」區塊按「Enable two-factor authentication」。
4. 建議選「Authenticator app」，用手機安裝 Google Authenticator 或 Microsoft Authenticator 掃描 QR Code。
5. 輸入 App 顯示的 6 位數完成設定。
6. GitHub 會給您一組「Recovery codes」（救援碼），請下載並印出收好。手機遺失時只能靠它登入。

---

## 二、建立 Token（每次到期都要重做一次）

1. 登入 GitHub，點右上角頭像，選「Settings」。
2. 左側選單拉到最下方，點「Developer settings」。
3. 左側點「Personal access tokens」，再點「Fine-grained tokens」。
4. 按右上角「Generate new token」。
5. 依下表填寫：

| 欄位 | 填寫內容 |
|---|---|
| Token name | 例如 `fireflyfarm-admin-2026` |
| Expiration | 建議 90 天。到期後重新建立即可 |
| Resource owner | `nice923boss`（您自己） |
| Repository access | 選「Only select repositories」，然後只勾選 `fireflyfarm` |
| Repository permissions | 找到「Contents」，改成「Read and write」。其餘全部維持 No access（Metadata 會自動變成 Read-only，這是正常的） |

6. 按最下方「Generate token」。
7. 畫面會顯示一串以 `github_pat_` 開頭的文字，**只會顯示這一次**。請立刻複製，貼到後台登入。
8. 不要把 Token 存在 LINE、Email、記事本或任何雲端文件。忘記了就回來重新建立一個新的，舊的刪掉。

### 為什麼要限制成「只有 fireflyfarm、只有 Contents」

即使 Token 外洩，拿到的人也只能改這個網站的檔案，不能動您 GitHub 帳號的其他東西，也不能刪除倉庫或改設定。

---

## 三、登入後台

1. 打開 <https://nice923boss.github.io/fireflyfarm/admin/>。
2. 把 Token 貼進「GitHub Fine-grained Token」欄位，按「登入後台」。
3. 後台會先向 GitHub 確認這把 Token 有寫入權限，失敗會顯示原因（Token 打錯、過期、權限不足）。
4. Token 只保存在這個瀏覽器分頁的暫存記憶體（sessionStorage）。關閉分頁或瀏覽器就消失，下次要重貼。這是刻意設計，不是故障。

「倉庫設定」通常不需要更改，只有在倉庫改名或搬家時才需要調整。

## 四、編輯內容

左側是八個區塊：

| 區塊 | 可以改什麼 |
|---|---|
| 網站設定 | 網站名稱、標語、SEO 標題與描述、共用連結（LINE、臉書、地圖、電話）、頂部導覽列、首頁主視覺與按鈕、頁尾、右下角浮動按鈕 |
| 專屬體驗 | 四張對象卡片的圖示、標題、項目、按鈕 |
| 住宿空間 | 房型卡片的分類、名稱、說明、房價、封面照、設備清單、寫真集，以及區塊標題與按鈕文字 |
| 四季旅行 | 四季卡片的圖示、時間、標題、說明、圖片、寫真集 |
| 美味與活動 | 餐飲與活動卡片的項目與備註 |
| 交通資訊 | 導航區塊與兩張須知清單 |
| 常見問題 | 分類、問題、答案段落（可加色塊、統計格、清單、聯絡框、按鈕列） |
| EDM 專案 | 兩個 EDM 視窗的標題、內文、報價、圖片、按鈕 |

操作重點：

- 每張卡片可用「↑ ↓」調整順序，「刪除」會先詢問確認。
- 所有按鈕都可以改文字，連結有四種：共用連結、跳到頁面區塊、開啟 EDM 視窗、自訂網址。電話、LINE、臉書、地圖改「網站設定」裡的共用連結一次，全站生效。
- 答案文字裡用 `**粗體**` 包住的字會顯示為粗體。
- 「預覽草稿」會用正式網站的版面顯示尚未發布的內容，看完按「回到後台」。
- 尚未發布的修改會暫存在這台電腦的瀏覽器裡（不含照片）。下次打開後台會問要不要接續。

### 上傳照片

1. 在圖片欄位按「更換圖片」或「＋ 新增照片」，選擇手機或電腦裡的照片。
2. 照片會在瀏覽器裡先縮小（長邊 1600 像素、JPEG 品質 0.8）再上傳，通常每張不到 500 KB。
3. 剛選好的照片會標示「尚未儲存」，要按「儲存並發布」才會真的上傳。
4. 換掉或刪掉的舊照片，發布時會一併從倉庫移除，不會佔空間。
5. 也可以在「或直接填外部圖片網址」貼上其他網站的圖片網址。

## 五、儲存並發布

1. 右上角「儲存並發布（N 區）」會顯示有幾個區塊被修改。
2. 按下後，後台會用您的 Token 把修改直接寫進 GitHub 倉庫（一次一個 commit，內含 JSON 資料與照片）。
3. 成功後顯示「已送出，約 1 至 2 分鐘後生效」，下方的部署狀態會自動更新：排隊中、進行中、成功或失敗。
4. 若顯示「最近一次部署失敗」，按「查看 Actions」可看到 GitHub 的錯誤紀錄，把畫面截圖給網站維護人員。
5. 發布後請到正式網站重新整理確認。手機瀏覽器有時要多等一下或清快取。

---

## 六、Token 外洩或懷疑外洩時：立刻撤銷

只要 Token 曾經貼錯地方、傳給別人、電腦借人用過，就當作外洩處理。撤銷不用錢、不影響網站，隨時可以做。

1. 登入 GitHub，右上角頭像，「Settings」。
2. 左側最下方「Developer settings」。
3. 「Personal access tokens」，「Fine-grained tokens」。
4. 找到該 Token，點進去，按「Delete」（或「Revoke」）並確認。
5. 撤銷後那把 Token 立即失效，後台會無法登入。回到第二節重新建立新 Token。
6. 到 <https://github.com/nice923boss/fireflyfarm/commits/main> 檢查有沒有不是您做的修改。若有，請通知網站維護人員回復到先前版本。

若懷疑的是 GitHub 帳號本身被登入，除了撤銷 Token，也請立刻在「Password and authentication」更改密碼，並檢查「Sessions」把不認識的裝置登出。

## 七、常見問題

**Q：後台網址被別人知道會不會有危險？**
不會。後台是公開的靜態頁面，沒有 Token 什麼都做不了。網站安全完全建立在「Token 不外流」與「GitHub 帳號有 2FA」這兩件事上。

**Q：Token 過期了怎麼辦？**
回到第二節重新建立一把。舊的 GitHub 會自動失效。

**Q：按了儲存卻出現「Token 沒有此倉庫的 Contents 寫入權限」？**
建立 Token 時「Repository permissions」的 Contents 沒有改成「Read and write」，或倉庫沒有勾到 `fireflyfarm`。請重建 Token。

**Q：可以兩個人同時編輯嗎？**
不建議。後台一次會寫入整個區塊的資料，兩人同時編輯同一區塊時，後儲存的人會蓋掉先儲存的人的內容。

**Q：想把網站回復到之前的樣子？**
每次發布都是一個 GitHub commit，維護人員可以從 <https://github.com/nice923boss/fireflyfarm/commits/main> 回復任何一個版本。
